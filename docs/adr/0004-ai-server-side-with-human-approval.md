# 0004: AI runs on the server; the tutor approves generated lessons

Date: 2026-09-27 · Status: Accepted

## Context
Lessons are generated by an LLM. Assessment uses speech-to-text plus LLM feedback. API keys must not ship in the app, costs must be capped, and incorrect Spanish must not reach the student unreviewed.

## Decision
- All LLM calls go through Supabase Edge Functions behind an `AiProvider` interface, so the vendor and model are config, not code.
- Generation uses structured output that matches the `LessonContent` JSON schema. The server validates it with zod and retries once if it is invalid.
- Generated lessons are stored as `draft`. Only the tutor can publish them.
- Per-user rate limits in the functions, plus a spend cap in the provider's console.
- Speech-to-text: on-device Whisper (`whisper.rn`) first, server Whisper as a fallback.
- Text-to-speech: the operating system's built-in voices (`expo-speech`).
- Every AI output records the model and prompt hash, so results can be traced and reproduced.

## Consequences
Lessons do not appear instantly (the tutor reviews them first). For a tutored course this is a benefit: the tutor stays in control of the curriculum.
